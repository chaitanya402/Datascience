### Word Doc Mobile App 📱

A complete React Native mobile application for creating and editing word documents on iOS and Android devices.

**Location**: `WordDocApp/`

**Features**:
- Create, edit, and delete documents
- Rich text formatting (bold, italic, underline)
- Font size adjustment
- Search documents
- Share documents
- Local storage
- Word and character count
- Material Design UI

**Quick Start**:
```bash
cd WordDocApp
npm install
npm run android  # or npm run ios
```
